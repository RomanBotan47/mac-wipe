# Безопасность и приватность

## Сообщить об уязвимости

Используйте **Security → Report a vulnerability** в этом репозитории. Технические ошибки без чувствительных данных можно отправлять в Issues. Пароли, токены и частные журналы в публичные сообщения не включайте.

## Границы приложения

«Протереть Mac» — локальная утилита для временной блокировки обычного ввода на время протирки. Программа использует AppKit, Core Graphics, Application Services, IOKit и Darwin. У приложения нет серверного компонента, удалённого управления, обновлятора, аналитики и телеметрии. Единственная внешняя ссылка открывается в системном браузере по нажатию пользователя.

Приложение получает Accessibility для фильтрации событий. Оно не считывает текст клавиатуры, не сохраняет нажатия, не сканирует файлы пользователя и не использует доступы автора к сервисам. Настройки — два локальных числа в UserDefaults.

Выходы: удержание мыши и отпускание, ⌘⌥Esc, автовыход 1–15 минут. Дочерний сторожевой процесс проверяет связь с собственным родительским процессом и завершает его при зависании или достижении срока. Административные права, демоны, launch agents и изменения системной защиты для работы не используются.

Аппаратная кнопка питания / Touch ID остаётся под управлением macOS. Протирка прекращается при переключении активного приложения, сне/смене сеанса, изменении экранов и отключении фильтра событий.

## Публикация и проверяемые ограничения

Публикуются только исходники, графика, документация и скрипты сборки/проверки. Каталоги сборок и резервных копий, конфиги сервисов, ключи, сертификаты и персональные файлы не входят в Git. Релизы собираются на GitHub-hosted runners без секретов автора; их файлы снабжены SHA-256.

Версия 1.1.1 подписывается ad-hoc и не нотариализирована Apple. Проверка исходников и тесты проекта не заменяют проверку Apple или независимый аудит. Подробности первого запуска — в README.
